# 非正規雇用・不本意非正規雇用 データ台帳

**作成日**: 2026-09-02  
**目的**: 本荘 2019 論文の雇用形態・総需要の議論を、現在の一次統計で検討し、独自の図表・分析資料を再現可能な形で作るための出発点。

## 用語上の注意

- **非正規の職員・従業員**: 労働力調査で勤務先の呼称により区分される統計カテゴリー。契約期間、労働時間、本人の希望と同義ではない。
- **不本意非正規雇用**: 非正規の職員・従業員のうち、現職の雇用形態に就いた主な理由を「正規の職員・従業員の仕事がないから」と回答した人を指す。
- 後者の減少だけで、非正規雇用全体の賃金、雇用安定、訓練機会、待遇格差が解消したとは結論できない。人数・理由・待遇を分けて追う。

## 独自分析の最初の3枚

1. **年次推移**: 2013年以降の非正規雇用者数・不本意非正規雇用者数・不本意非正規率を同じ図に置く。率の分母を図注に明記する。
2. **属性別の分布**: 直近年について性別・年齢別の不本意非正規率を棒グラフにする。人数と率を混同しないよう、必要なら二図に分ける。
3. **マクロ接続**: 雇用者報酬、家計最終消費支出、名目GDPの前年比を重ね、本荘論文の仮説を「説明すべき関係」として示す。雇用形態の変化だけによる因果と断定しない。

## 再現可能な作業手順

1. 各表の公表年・表番号・ダウンロード日・単位・分母を `data/README.md` に記録する。
2. 原表は `data/raw/` に保存し、加工済みCSVは `data/processed/` に分ける。
3. 加工・描画コードは `scripts/` に置き、図のタイトル、単位、出典、作成日をコードから出力する。
4. 数値の転記ではなく、表形式データから図を生成する。原表の改定時に再実行できる状態を保つ。

## 対話で確認する問い

- 「正規の仕事がないから」という不本意区分は、正規雇用を望むという非自発性をどこまで捉えているか。
- 不本意非正規率の低下と、賃金・訓練・安定性を含む雇用の質の改善を、どのように区別して評価すべきか。
- 本荘論文の仮説を現在のデータで検討する場合、雇用形態、雇用者報酬、消費の関係をどの単位・期間で扱うのが妥当か。
